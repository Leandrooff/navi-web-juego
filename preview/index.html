NAVI Web Juego separado por pantallas

Esta vista previa ya no mezcla todo en una sola pagina. Cada modulo tiene su propia pantalla para que cada grupo entienda que debe crear.

Flujo general

  1. El nino elige una aventura.
  2. Lee o escucha la escena.
  3. Toma una decision.
  4. El sistema registra puntos.
  5. Tutor y educador revisan resultados.
