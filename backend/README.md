# Backend NAVI

Esta carpeta queda como base para el backend final con Laravel API, autenticacion, roles y panel administrativo.

## Herramientas previstas

- PHP
- Composer
- Laravel
- Laravel Sanctum
- Filament
- Postman o Insomnia

## Instalacion sugerida

Cuando el equipo empiece a construir el backend final:

```bash
cd backend
composer create-project laravel/laravel .
composer require laravel/sanctum
composer require filament/filament
php artisan serve
```
