# Reparto de trabajo para 14 personas

El equipo se divide en 7 parejas. Cada pareja trabaja un modulo independiente. El usuario responsable principal cuenta como 2 personas, por lo tanto ocupa una pareja completa.

## Pareja 1 Modulo 01 Diseno UI y experiencia de juego

Integrantes:

- Persona 1
- Persona 2

Carpeta:

```text
modules/01-diseno-ui-juego
```

Responsabilidad:

Disenar la experiencia visual del juego, pantallas, mapa de navegacion, estilo infantil, botones, avatares, logros y prototipo en Figma.

## Pareja 2 Modulo 02 Frontend y motor de cuentos

Integrantes:

- Persona 3
- Persona 4

Carpeta:

```text
modules/02-frontend-motor-cuentos
```

Responsabilidad:

Construir la interfaz web jugable en React. Debe permitir cargar cuentos, mostrar escenas, reproducir audio, mostrar opciones y avanzar segun la decision.

## Pareja 3 Modulo 03 Backend API autenticacion y roles

Integrantes:

- Persona 5
- Persona 6

Carpeta:

```text
modules/03-backend-api-auth
```

Responsabilidad:

Crear el backend en Laravel, autenticacion, roles, permisos, rutas API y control de acceso para nino, tutor, educador y administrador.

## Pareja 4 Modulo 04 Panel administrador de contenidos

Integrantes:

- Persona 7
- Persona 8

Carpeta:

```text
modules/04-panel-admin-contenidos
```

Responsabilidad:

Crear el panel para que el administrador gestione categorias, cuentos, escenas, opciones, imagenes, audios y publicacion de cuentos.

## Pareja 5 Modulo 05 Base de datos y modelo de informacion

Integrantes:

- Persona 9
- Persona 10

Carpeta:

```text
modules/05-base-datos-modelo
```

Responsabilidad:

Disenar la base de datos, diagrama entidad relacion, diccionario de datos, migraciones y datos de prueba.

## Pareja 6 Modulo 06 Reportes seguimiento y recomendaciones

Integrantes:

- Persona 11
- Persona 12

Carpeta:

```text
modules/06-reportes-seguimiento
```

Responsabilidad:

Crear la logica de resultados, puntajes, estrellas, logros, recomendaciones y vistas para tutores y educadores.

## Pareja 7 Modulo 07 Integracion pruebas y documentacion

Integrantes:

- Tu como responsable principal
- Tu como responsable tecnico y de integracion

Carpeta:

```text
modules/07-integracion-qa
```

Responsabilidad:

Integrar avances, revisar Pull Requests, probar modulos, documentar instalacion final, preparar presentacion y asegurar que el proyecto corra completo.

## Forma de trabajo

Cada pareja debe entregar:

- Rama propia en Git.
- README del modulo actualizado.
- Capturas o evidencia de avance.
- Codigo o prototipo correspondiente.
- Datos de prueba si su modulo lo necesita.
- Instrucciones para probar su parte sin depender de otros modulos.
