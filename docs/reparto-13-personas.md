# Reparto individual para 13 personas

El proyecto se trabajara de forma individual. Cada persona tiene una carpeta propia dentro de `modules/` y debe subir ahi sus avances.

## 01 Alcides Diseno UI

Carpeta:

```text
modules/01-alcides-diseno-ui
```

Responsabilidad:

Definir identidad visual, colores, pantallas base, botones, tarjetas y experiencia infantil.

## Entrega minima por persona

Cada persona debe entregar:

- Avance dentro de su carpeta.
- README o `base-avance/avance.md` actualizado.
- Capturas, codigo, documento o datos segun su responsabilidad.
- Instrucciones para revisar su parte.
- Dudas o pendientes claros.
