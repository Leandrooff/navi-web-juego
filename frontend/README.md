# Frontend NAVI

Esta carpeta queda lista como base para el frontend final con React, Vite y Tailwind CSS.

## Herramientas previstas

- React
- Vite
- Tailwind CSS
- JavaScript

## Instalacion sugerida

Cuando el equipo empiece a programar el frontend final:

```bash
cd frontend
npm install
npm run dev
```

## Vista previa actual

Mientras no se instalen dependencias, usar la preview ejecutable:

```text
../preview/index.html
```
