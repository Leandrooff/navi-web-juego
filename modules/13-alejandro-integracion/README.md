# Modulo 13 Alejandro Integracion y fusion final

## Objetivo

Este modulo es para Alejandro. La funcion principal no es hacer otra pantalla aislada, sino fusionar todo lo que suban los demas.

Leer tambien `INSTRUCCIONES.md` dentro de esta misma carpeta para ver exactamente que debes integrar.

## Responsabilidades

- Revisar Pull Requests.
- Ver que cada persona haya subido su avance en su carpeta.
- Corregir conflictos de archivos.
- Unir pantallas, componentes, datos, API y estilos.
- Decidir que entra en la version final.
- Ordenar nombres de archivos y carpetas.
- Hacer que el proyecto completo corra.

## Flujo de integracion

1. Revisar modulo por modulo.
2. Copiar o adaptar las partes utiles al frontend/backend final.
3. Conectar datos demo.
4. Corregir estilos para que todo se vea uniforme.
5. Probar que la navegacion principal funcione.
6. Dejar una version presentable.

## Entrega esperada

- Lista de avances recibidos.
- Pendientes por persona.
- Version final integrada.
