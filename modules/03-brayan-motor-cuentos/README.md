# Modulo 03 Brayan Motor de cuentos

## Objetivo

Crear la logica principal del juego: leer escenas, mostrar decisiones, sumar puntos y llegar a un final.

Leer tambien `../../docs/instrucciones-detalladas-entrega.md` para ver la estructura exacta de entrega.

## Pantallas a desarrollar

- Escena del cuento.
- Lista de opciones.
- Resultado despues de elegir.
- Final del cuento.

## Funciones necesarias

- Cargar un cuento desde JSON.
- Mostrar escena actual.
- Mostrar opciones disponibles.
- Detectar opcion seleccionada.
- Cambiar a la siguiente escena.
- Sumar puntos segun la opcion.
- Guardar historial de decisiones.
- Calcular final bueno, intermedio o malo.
- Reiniciar cuento.

## Datos demo sugeridos

Crear `cuento-demo.json` con:

- `id`
- `titulo`
- `escenas`
- `opciones`
- `puntaje`
- `siguienteEscena`
- `finales`

## Entrega esperada

Subir un cuento jugable aunque sea simple. Lo importante es que se pueda avanzar entre escenas.
