# Instrucciones para Ruth Serrano - Reportes de progreso

## Objetivo exacto

Crear pantallas para que tutor o educador vea el avance del nino.

## Estructura que debes seguir

```text
modules/09-ruth-serrano-reportes/
  README.md
  INSTRUCCIONES.md
  base-avance/
    avance.md
  src/
    dashboard-progreso.html
    reporte-detalle.html
    reportes.js
    reportes.css
  demo/
    progreso-demo.json
```

## Pantallas que debes subir

- Dashboard de progreso.
- Historial de cuentos jugados.
- Detalle de decisiones tomadas.
- Temas a reforzar.
- Resumen de estrellas y logros.

## Funciones que debe tener

- Mostrar porcentaje de avance.
- Mostrar cuentos completados.
- Mostrar puntaje total.
- Mostrar estrellas acumuladas.
- Mostrar decisiones correctas e incorrectas.
- Filtrar por cuento.
- Mostrar recomendacion para tutor.

## Datos demo obligatorios

Crear `demo/progreso-demo.json` con:

- Nombre del nino.
- Lista de cuentos jugados.
- Puntaje por cuento.
- Decisiones tomadas.
- Recomendaciones.

## Que escribir en avance.md

- Que reportes se pueden ver.
- Que filtros funcionan.
- Donde estan los datos demo.
- Que falta conectar.
