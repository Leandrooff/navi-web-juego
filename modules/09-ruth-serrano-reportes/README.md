# Modulo 09 Ruth Serrano Reportes de progreso

## Objetivo

Crear pantallas para que tutor o educador vea el avance del nino.

Leer tambien `../../docs/instrucciones-detalladas-entrega.md` para ver la estructura exacta de entrega.

## Pantallas a desarrollar

- Dashboard de progreso.
- Historial de cuentos jugados.
- Detalle de decisiones tomadas.
- Temas a reforzar.
- Resumen de estrellas y logros.

## Funciones necesarias

- Mostrar porcentaje de avance.
- Mostrar cuentos completados.
- Mostrar puntaje total.
- Mostrar estrellas acumuladas.
- Mostrar decisiones correctas e incorrectas.
- Filtrar por cuento.
- Mostrar recomendacion para tutor.

## Datos demo sugeridos

Crear datos de 2 ninos con cuentos jugados, puntajes y decisiones.

## Entrega esperada

Subir dashboard o pantalla funcional con datos demo.
