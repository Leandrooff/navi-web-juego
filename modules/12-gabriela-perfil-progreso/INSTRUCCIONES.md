# Instrucciones para Gabriela - Perfil y progreso

## Objetivo exacto

Crear la zona personal del nino con perfil, progreso, cuentos guardados y ultima actividad.

## Estructura que debes seguir

```text
modules/12-gabriela-perfil-progreso/
  README.md
  INSTRUCCIONES.md
  base-avance/
    avance.md
  src/
    perfil.html
    progreso-personal.html
    perfil.js
    perfil.css
  demo/
    perfil-demo.json
```

## Pantallas que debes subir

- Perfil del nino.
- Progreso personal.
- Cuentos completados.
- Ultima aventura jugada.
- Logros recientes.

## Funciones que debe tener

- Mostrar nombre del usuario.
- Mostrar rol.
- Mostrar avatar o icono.
- Mostrar cuentos completados.
- Mostrar estrellas acumuladas.
- Mostrar logros recientes.
- Boton continuar ultima aventura.
- Configuracion basica del perfil.
- Resumen de actividad.

## Datos demo obligatorios

Crear `demo/perfil-demo.json` con:

- `nombre`
- `rol`
- `avatar`
- `estrellas`
- `cuentosCompletados`
- `ultimaAventura`
- `logrosRecientes`

## Que escribir en avance.md

- Que datos muestra.
- Que botones funcionan.
- Como se podria conectar con login y reportes.
- Que falta terminar.
