# Avance Gabriela

## Que subi

- Pantalla de perfil del niño.
- Pantalla de progreso personal.
- Datos demo del perfil.
- Logros recientes, ultima aventura, estrellas y cuentos completados.
- Configuracion basica de sonido, texto y contraste.

## Como verlo

Abrir `src/perfil.html`.

Desde esa pantalla se puede entrar a `src/progreso-personal.html`.

## Botones que funcionan

- Continuar aventura muestra la aventura que se continuaria.
- Perfil y Progreso cambian entre las dos pantallas.
- Sonido, Texto y Contraste cambian su estado en la demo.

## Falta

- Conectar el usuario real cuando este listo el login.
- Traer progreso real desde reportes o base de datos.
- Conectar el boton continuar con el motor de cuentos.
