# Modulo 12 Gabriela Peñaranda Perfil y progreso

## Objetivo

Crear la zona personal del nino con perfil, progreso, cuentos guardados y ultima actividad.

Leer tambien `../../docs/instrucciones-detalladas-entrega.md` para ver la estructura exacta de entrega.

## Pantallas a desarrollar

- Perfil del nino.
- Progreso personal.
- Cuentos completados.
- Ultima aventura jugada.
- Logros recientes.

## Funciones necesarias

- Mostrar nombre y rol.
- Mostrar avatar o icono.
- Mostrar cuentos completados.
- Mostrar estrellas acumuladas.
- Mostrar logros recientes.
- Boton para continuar ultima aventura.
- Editar datos basicos del perfil.
- Mostrar resumen de actividad.

## Datos demo sugeridos

Crear `perfil-demo.json` con nombre, rol, avatar, cuentos completados, estrellas, logros y ultima aventura.

## Entrega esperada

Subir pantalla de perfil/progreso con datos demo.
