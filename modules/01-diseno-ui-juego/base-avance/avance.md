## Que debe desarrollar este grupo

Este grupo debe definir como se vera NAVI como juego web infantil. No necesita programar todavia, pero debe dejar claro el estilo visual y las pantallas principales.

## Archivos que deben subir aqui

- Link o capturas del prototipo en Figma.
- Pantallas principales en PNG o PDF.
- Paleta de colores.
- Tipografias sugeridas.
- Iconos o referencias visuales.
- Explicacion corta de cada pantalla.

## Pantallas base

- Inicio del juego.
- Seleccion de avatar o perfil infantil.
- Biblioteca de aventuras.
- Pantalla de escena.
- Pantalla de decision.
- Pantalla de resultado.
- Pantalla de logros.
- Vista simple para tutor o educador.

## Como debe quedar para revisar

Una persona externa debe poder abrir las capturas o el link de Figma y entender como se navegara por el juego.
