# Modulo 01 Diseno UI y experiencia de juego

## Objetivo

Definir como se vera y se sentira NAVI como pagina web tipo juego para ninos de 6 a 10 anos.

## Herramientas

- Figma.
- Navegador web.
- Paleta de colores accesible.
- Material de referencia infantil educativo.

## Entregables

- Prototipo en Figma.
- Mapa de pantallas.
- Guia visual basica.
- Componentes principales.
- Capturas exportadas en PNG o PDF.

## Pantallas minimas

- Inicio del juego.
- Seleccion de perfil o avatar.
- Biblioteca de aventuras.
- Pantalla de escena.
- Pantalla de decision.
- Pantalla de resultado.
- Logros.
- Vista simple para tutor o educador.

## Reglas de diseno

- Botones grandes.
- Textos cortos.
- Alto contraste.
- Iconos claros.
- Colores amigables sin saturar.
- Evitar contenido que provoque miedo innecesario.

## Como trabajar independiente

No necesitan backend ni frontend terminado. Deben entregar disenos y especificaciones para que otros modulos puedan programar.
