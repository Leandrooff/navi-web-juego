# Modulo 04 Panel administrador de contenidos

## Objetivo

Crear el panel donde el administrador pueda gestionar el contenido del juego.

## Herramientas

- Laravel.
- Filament.
- Base de datos local.
- Almacenamiento de imagenes y audios.

## Entregables

- CRUD de categorias.
- CRUD de cuentos.
- CRUD de escenas.
- CRUD de opciones.
- Carga de imagenes.
- Carga de audios.
- Estado borrador/publicado.
- Validacion de rutas incompletas.

## Regla de publicacion

Un cuento solo puede publicarse si:

- Tiene escena inicial.
- Todas las opciones tienen destino.
- No hay escenas sueltas.
- Las escenas requeridas tienen texto.
- Los archivos obligatorios existen.

## Como trabajar independiente

Pueden trabajar con modelos temporales y datos locales. Deben documentar que campos necesita cada formulario.
