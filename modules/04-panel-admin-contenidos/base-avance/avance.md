## Que debe desarrollar este grupo

Este grupo debe crear el panel donde el administrador pueda cargar y editar el contenido del juego.

## Archivos que deben subir aqui

- Capturas del panel.
- Formularios creados.
- Campos necesarios por formulario.
- Reglas para publicar cuentos.
- Instrucciones para probar.

## CRUDs base

- Categorias.
- Cuentos.
- Escenas.
- Opciones.
- Imagenes.
- Audios.

## Regla importante

Un cuento no debe publicarse si tiene:

- Opciones sin destino.
- Escenas sin conexion.
- Archivos faltantes.
- Falta de escena inicial.

## Como debe quedar para revisar

Debe quedar claro como un administrador crearia un cuento interactivo desde cero.
