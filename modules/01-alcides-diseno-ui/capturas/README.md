# Capturas · Módulo 01 · Diseño visual

Capturas que acompañan el PR. Se toman con la app corriendo (`docs/INSTALACION.md`) en http://127.0.0.1:5173, con una cuenta y un perfil de prueba con datos inventados. No deben aparecer correos, nombres ni datos reales.

## Cómo tomarlas
1. Abrir las herramientas de desarrollo del navegador (F12) y activar la vista de dispositivo (Ctrl + Shift + M).
2. Para móvil, fijar **360 × 800**. Para escritorio, **1280 × 800** o más.
3. Usar la captura de página completa (menú ⋮ de la vista de dispositivo → «Capturar captura de pantalla de tamaño completo»).
4. Guardar los archivos en esta carpeta con los nombres de la tabla.
