# Instrucciones para Alcides - Diseno UI

## Objetivo exacto

Crear la base visual del juego NAVI. Tu trabajo debe servir como referencia para que todos usen el mismo estilo.

## Estructura que debes seguir

```text
modules/01-alcides-diseno-ui/
  README.md
  INSTRUCCIONES.md
  base-avance/
    avance.md
  src/
    pantalla-inicio.html
    pantalla-biblioteca.html
    pantalla-juego.html
    pantalla-resultado.html
    estilos-ui.css
  assets/
    logo-navi.png
    icono-cuento.png
    icono-estrella.png
```

## Pantallas que debes subir

- Pantalla de inicio con titulo NAVI, boton comenzar, boton biblioteca y acceso a perfil.
- Pantalla de biblioteca con tarjetas de cuentos.
- Pantalla de juego con imagen, texto, opciones y puntos.
- Pantalla final con estrellas, mensaje positivo y boton de volver.
- Estado vacio cuando no haya cuentos disponibles.

## Funciones visuales que debe tener

- Paleta de colores principal.
- Boton principal, secundario y deshabilitado.
- Tarjetas de cuento con estados: nuevo, en progreso, completado y bloqueado.
- Estilos de mensajes: positivo, advertencia y error.
- Iconos o imagenes sugeridas para cuento, logro y usuario.

## Entrega minima

- Archivos HTML/CSS o React.
- Colores definidos.
- Componentes visuales principales.
- Explicacion corta en `base-avance/avance.md`.

## Que escribir en avance.md

- Que pantallas subiste.
- Que archivo se abre primero.
- Que colores recomiendas.
- Que falta terminar.
