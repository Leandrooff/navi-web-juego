# Modulo 01 Alcides Diseno UI

## Objetivo

Crear la identidad visual y las pantallas base del juego NAVI. Este modulo debe servir como referencia visual para que los demas usen colores, botones, tarjetas y estilos parecidos.

Leer tambien `../../docs/instrucciones-detalladas-entrega.md` para ver la estructura exacta de entrega.

## Pantallas a desarrollar

- Inicio del juego con titulo NAVI, boton de comenzar y acceso a biblioteca.
- Seleccion de aventura con tarjetas de cuentos.
- Pantalla de cuento con zona de imagen, texto y opciones.
- Pantalla de resultado con estrellas, mensaje y boton de continuar.
- Estado vacio cuando no hay cuentos disponibles.

## Funciones visuales necesarias

- Definir paleta de colores.
- Crear estilos de boton principal, secundario y deshabilitado.
- Crear tarjetas de cuento con estado: nuevo, en progreso, completado y bloqueado.
- Crear estilos para mensajes positivos, advertencias y errores.
- Definir iconos o imagenes sugeridas para cuento, logro y usuario.

## Archivos sugeridos

- `pantalla-inicio.html` o `pantalla-inicio.jsx`
- `pantalla-juego.html` o `pantalla-juego.jsx`
- `estilos-ui.css`
- `colores.md`

## Entrega esperada

Subir una version visual clara. No hace falta que funcione con backend; debe verse bien y ser facil de integrar.
