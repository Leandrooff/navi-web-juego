## Que debe desarrollar este grupo

Este grupo debe definir como se calcularan resultados, estrellas, logros, progreso y recomendaciones.

## Archivos que deben subir aqui

- Reglas de puntaje.
- Reglas de estrellas.
- Logros propuestos.
- Ejemplos de recomendaciones.
- Prototipo o captura de reportes.
- Datos de prueba.

## Reglas sugeridas

```text
Decision segura: 10 puntos
Decision intermedia: 5 puntos
Decision riesgosa: 0 puntos
```

```text
3 estrellas: 80 a 100 puntos
2 estrellas: 50 a 79 puntos
1 estrella: 0 a 49 puntos
```

## Reportes base

- Resultado por cuento.
- Progreso por categoria.
- Cuentos completados.
- Recomendaciones para reforzar.
- Vista individual para tutor.
- Vista grupal para educador.

## Como debe quedar para revisar

Debe poder probarse con datos inventados o JSON, sin esperar a que el frontend este listo.
