# Modulo 06 Reportes seguimiento y recomendaciones

## Objetivo

Definir y construir la logica de resultados del juego: puntajes, estrellas, logros, progreso y recomendaciones.

## Herramientas

- Laravel o JavaScript para prototipo.
- Postman.
- Datos JSON o SQL de prueba.

## Entregables

- Regla de puntaje.
- Regla de estrellas.
- Logros disponibles.
- Recomendaciones por categoria.
- Vista o prototipo de reporte para tutor.
- Vista o prototipo de reporte para educador.

## Reglas sugeridas

```text
Decision segura: 10 puntos
Decision intermedia: 5 puntos
Decision de riesgo: 0 puntos
```

```text
3 estrellas: 80 a 100 puntos
2 estrellas: 50 a 79 puntos
1 estrella: 0 a 49 puntos
```

## Recomendaciones

Las recomendaciones no deben sonar negativas. Deben reforzar:

- Que hizo bien.
- Que puede practicar.
- Que tema debe revisar con un adulto.

## Como trabajar independiente

Pueden simular decisiones con JSON y generar resultados sin esperar al frontend o backend.
