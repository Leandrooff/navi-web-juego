# Instrucciones para Fabian - Componentes frontend

## Objetivo exacto

Crear componentes reutilizables para que las pantallas se armen mas rapido y con el mismo estilo.

## Estructura que debes seguir

```text
modules/04-fabian-componentes-frontend/
  README.md
  INSTRUCCIONES.md
  base-avance/
    avance.md
  src/
    Button.jsx
    StoryCard.jsx
    ProgressBar.jsx
    ChoiceButton.jsx
    Modal.jsx
    componentes.css
  demo/
    componentes-demo.html
```

## Componentes que debes subir

- Boton principal.
- Boton secundario.
- Tarjeta de cuento.
- Tarjeta de logro.
- Barra de progreso.
- Boton de opcion para decisiones.
- Modal de confirmacion.
- Mensaje de alerta.

## Funciones que debe tener

- Cada componente debe recibir datos por parametro o props.
- Estados: normal, activo, deshabilitado y error.
- Adaptacion a celular.
- Ejemplo visual de cada componente.

## Que escribir en avance.md

- Que componentes subiste.
- Donde estan los ejemplos.
- Si estan en React, HTML o ambos.
- Que falta adaptar.
