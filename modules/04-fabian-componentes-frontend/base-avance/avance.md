# Avance del modulo

## Responsable

Fabian

## Que subi

- Componentes React para botones, tarjetas de cuento y logro, barra de progreso, opciones de decisión, modal de confirmación, alertas y layout base.
- Estados visuales normales, activos, deshabilitados, completados y de error según corresponda.
- Estilos responsive con la paleta de colores de NAVI y foco visible para navegación con teclado.

## Como verlo

Abre `demo/componentes-demo.html` directamente en el navegador para ver y probar la galería. Los componentes React y sus estilos están en `src/`; consulta el `README.md` de este módulo para ejemplos de integración.

## Tecnologia

Los componentes están en React y la galería de demostración está en HTML, CSS y JavaScript sin dependencias externas.
