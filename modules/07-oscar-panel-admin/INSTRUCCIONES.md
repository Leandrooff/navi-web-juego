# Instrucciones para Oscar - Panel administrador

## Objetivo exacto

Crear el panel donde el administrador pueda crear y editar cuentos, escenas y opciones.

## Estructura que debes seguir

```text
modules/07-oscar-panel-admin/
  README.md
  INSTRUCCIONES.md
  base-avance/
    avance.md
  src/
    admin-dashboard.html
    cuentos-form.html
    escenas-form.html
    admin.js
    admin.css
  demo/
    cuentos-admin-demo.json
```

## Pantallas que debes subir

- Dashboard administrador.
- Lista de cuentos.
- Crear cuento.
- Editar cuento.
- Crear escena.
- Editar escena.
- Crear opciones de decision.

## Funciones que debe tener

- Crear cuento.
- Editar cuento.
- Cambiar estado: borrador o publicado.
- Crear escenas.
- Ordenar escenas.
- Crear opciones con texto, puntaje y siguiente escena.
- Ver resumen antes de publicar.

## Campos minimos del cuento

- Titulo.
- Categoria.
- Descripcion.
- Imagen.
- Edad recomendada.
- Estado.

## Que escribir en avance.md

- Que formularios subiste.
- Que datos demo usaste.
- Que botones funcionan.
- Que falta guardar.
