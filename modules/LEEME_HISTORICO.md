# Aportes originales del equipo

Estos módulos se conservan como material académico y trazabilidad. Algunos contienen demostraciones con datos o autenticación simulada. No se sirven como parte de NAVI y no deben desplegarse directamente.

La aplicación integrada está en ../frontend y ../backend. El código de producción usa cuentas Laravel, MariaDB y autorización en el servidor. Las instrucciones vigentes están en ../docs/INSTALACION.md.
