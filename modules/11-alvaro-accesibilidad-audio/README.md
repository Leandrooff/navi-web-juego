# Modulo 11 Alvaro Rosas Accesibilidad y audio

## Objetivo

Crear funciones para que el juego sea mas facil de usar para ninos: lectura, audio, ayuda visual y controles simples.

## Pantallas a desarrollar

- Panel de accesibilidad.
- Controles de audio.
- Modo lectura.
- Boton de ayuda dentro del juego.

## Funciones necesarias

- Leer texto de escena en voz alta.
- Repetir audio de la escena.
- Activar o desactivar sonido.
- Controlar volumen.
- Cambiar tamano de letra.
- Activar alto contraste.
- Mostrar ayuda rapida sobre que hacer.
- Boton para volver a escuchar una opcion.

## Archivos sugeridos

- `accesibilidad.html`
- `audio-controls.js`
- `modo-lectura.css`

## Entrega esperada

Subir componentes o funciones demo que luego se puedan integrar en la pantalla del cuento.
