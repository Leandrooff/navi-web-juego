## Que debe desarrollar este modulo

Este modulo se encarga de ordenar el proyecto completo, revisar avances, integrar Pull Requests y preparar la entrega final.

## Archivos que se deben guardar aqui

- Checklist de revision.
- Estado de avance de cada modulo.
- Bugs encontrados.
- Capturas finales.
- Guia de instalacion final.
- Notas para la presentacion.

## Checklist base de revision

- Cada grupo trabaja en su carpeta.
- Cada grupo sube instrucciones claras.
- Cada grupo deja evidencia de avance.
- Ningun grupo rompe la estructura general.
- Los modulos se pueden integrar.
- Hay una version final ejecutable o presentable.
