# Modulo 07 Integracion pruebas y documentacion final

## Objetivo

Integrar los modulos, revisar calidad, preparar la documentacion final y asegurar que el proyecto se pueda ejecutar para la presentacion.

## Responsable

Este modulo queda asignado al usuario principal, contando como dos personas del equipo de 14.

## Herramientas

- GitHub.
- Git.
- Visual Studio Code.
- Postman o Insomnia.
- Navegador.
- Checklist de pruebas.

## Entregables

- Revision de Pull Requests.
- Checklist de integracion.
- Guia final de instalacion.
- Pruebas funcionales.
- Capturas para presentacion.
- Control de bugs.
- Version final en rama `main`.

## Checklist minimo

- El proyecto clona correctamente.
- El frontend inicia.
- El backend inicia.
- El login funciona.
- Existe al menos un cuento jugable.
- El cuento registra decisiones.
- El resultado final muestra estrellas.
- El tutor o educador puede revisar resultados.
- El panel admin puede crear o editar un cuento.

## Como trabajar independiente

Aunque los demas modulos no esten listos, este modulo debe mantener la documentacion, ramas, estructura del repositorio y criterios de aceptacion.
