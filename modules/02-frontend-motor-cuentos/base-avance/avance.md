## Que debe desarrollar este grupo

Este grupo debe crear la parte jugable en React. La idea es que el nino pueda ver una escena, elegir una opcion y avanzar a otra escena.

## Archivos que deben subir aqui

- Componentes creados.
- Capturas del frontend.
- JSON de cuento de prueba.
- Instrucciones para ejecutar.
- Lista de pantallas terminadas.

## Base minima esperada

- Pantalla de biblioteca.
- Pantalla de juego.
- Componente de escena.
- Botones de opciones.
- Avance entre escenas.
- Resultado final.

## Datos de ejemplo sugeridos

Crear un cuento de prueba sobre:

```text
Me perdi en el parque
```

El cuento debe tener por lo menos:

- 1 escena inicial.
- 3 escenas intermedias.
- 2 decisiones.
- 1 final seguro.
- 1 final de refuerzo.

## Como debe quedar para revisar

Debe poder probarse aunque no exista backend, usando JSON local.
