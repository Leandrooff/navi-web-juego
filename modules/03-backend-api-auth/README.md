# Modulo 03 Backend API autenticacion y roles

## Objetivo

Crear el backend en Laravel para manejar usuarios, autenticacion, roles y rutas API.

## Herramientas

- PHP.
- Composer.
- Laravel.
- Laravel Sanctum.
- Postman o Insomnia.

## Roles del sistema

- Nino o perfil infantil.
- Tutor.
- Educador.
- Administrador.

## Entregables

- Proyecto Laravel base.
- Autenticacion.
- Roles y permisos.
- Endpoints documentados.
- Coleccion Postman o Insomnia.
- Middleware de acceso por rol.

## Endpoints minimos

```text
POST /api/login
POST /api/logout
GET /api/me
GET /api/stories
GET /api/stories/{id}
POST /api/child-profiles
GET /api/child-profiles
```

## Como trabajar independiente

Pueden crear respuestas de prueba para cuentos mientras la base de datos final no este lista. Lo importante es dejar clara la forma de los endpoints.
